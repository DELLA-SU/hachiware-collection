# 하치왕왕 도감

파스텔 러브레터 콜라주 스타일로 하치와레·치이카와·우사기 사진을 모으는 웹사이트입니다.

- 사진 뽑기, 번호·날짜·캐릭터 검색, 별표, 삭제 및 바로 복원
- 사진마다 메모와 드로잉, 확대·이동, 출처 링크
- 하치와레 노래 TV, 도감이 펼쳐지는 인트로
- 원본 영상에서 편집한 우사기 목소리 14개를 중복 없이 섞어 재생
- 동작별 짧은 효과음과 음소거
- 배너와 수집 현황 디자인 비교 페이지 5종

공개판의 기록은 **방문자의 브라우저 IndexedDB**에 저장됩니다. 서버에 개인 메모나 드로잉을 전송하지 않습니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터 삭제 시 기록도 사라집니다. 기록 내보내기는 사진 목록, 별표, 메모, 드로잉을 JSON으로 저장합니다.

사진 뽑기는 출처를 확인한 55개 사진 중 아직 모으지 않은 사진을 선택합니다. 전부 모으면 기존 사진을 다시 보여주고 중복 카드를 생성하지 않습니다. 공개판은 실시간 Pinterest 검색을 수행하지 않습니다.

## 실행 및 배포

Node.js 22 이상에서 `npm install`, `npm run dev`로 실행합니다. `npm run build`는 GitHub Pages에 올릴 `docs/`를 생성합니다.

GitHub Pages 설정: `main` 브랜치의 `/docs` 폴더. 경로는 `/hachiware-collection/`입니다. 이미지, 음성, 스크립트는 해당 경로에 맞춰 구성되어 있습니다. `docs/.nojekyll`을 유지하세요.

- `banner-letter-preview.html`: 추가 배너 시안 5종
- `usagi-voices-preview.html`: 편집한 우사기 목소리 재생

개인 메모·드로잉 데이터, 로컬 서버 DB, macOS 실행 파일, 인증 정보는 저장소에 포함하지 않습니다. 캐릭터와 원본 사진·영상·음성의 권리는 해당 원저작자에게 있으며, 사진별 출처 링크를 제공합니다.
