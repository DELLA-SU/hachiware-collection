개인정보 및 쿠키 안내

치이카와 가챠 · 웹 도감 / 자격증 / 파자마 페이지
최종 수정: 2026년 11월 15일
내 도감의 기록은 현재 브라우저에 저장돼요.

별표, 사진별 메모와 드로잉은 웹 도감의 서버로 업로드되지 않습니다. 다른 기기나 브라우저와 자동으로 동기화되지 않으며, 브라우저 데이터를 지우면 기록이 사라질 수 있어요.

1. 사진과 설정의 저장

도감 목록·별표·메모·드로잉은 브라우저 저장소(IndexedDB)에, 언어·효과음·방문 통계 선택 등은 브라우저의 설정 저장소(localStorage)에 보관합니다. 사이트 기능을 위한 저장이며 광고 쿠키와 구분됩니다.

자격증이나 파자마 꾸미기에 적용한 사진과 입력 내용은 브라우저에서 처리합니다. ‘최애 한 장 공유하기’는 별도의 게시판 서비스로 이동하며, 게시판에서 직접 공개한 사진·닉네임·설명은 다른 사람이 볼 수 있습니다.

도감의 기록 내보내기 기능으로 백업할 수 있습니다. 기록을 완전히 지우려면 브라우저의 사이트 데이터 삭제 기능을 이용해 주세요. 사이트 데이터를 지우기 전에 필요한 기록을 백업해 주세요.

2. 방문 통계

Umami: 쿠키 없이 페이지 조회와 정해진 기능 사용 횟수를 집계합니다. 사이트는 페이지 경로, 유입 출처의 도메인, 언어·화면 크기 및 기능 이벤트를 전송하며, 사진 파일·이름·검색어·메모·드로잉을 통계 항목으로 보내지 않습니다. 통계 서비스 연결 시 IP 주소와 브라우저 정보가 서비스 제공자에게 전달될 수 있습니다.

Google Analytics 4: 방문자가 ‘Google 통계 설정’에서 허용한 경우에만 연결합니다. 허용한 뒤의 페이지 조회·기능 이벤트·유입 경로·기기 정보를 처리하고 분석 쿠키를 사용할 수 있습니다. 이 사이트의 GA4 설정에서는 광고 개인화와 Google Signals를 사용하지 않습니다.

Umami는 도감의 ‘설정과 안내 → 효과음·언어 설정 → 방문 통계 설정’에서 끌 수 있습니다. GA4는 각 페이지 아래의 ‘Google 통계 설정’에서 변경할 수 있습니다. GA4를 거절하면 이후 통계 전송을 막고 이 프로젝트의 분석 쿠키를 지웁니다. 두 서비스의 선택은 별도로 적용되며 브라우저의 Do Not Track 설정을 존중합니다.

GA4 분석 쿠키의 설정상 보관 기간은 약 6개월입니다. 도감 기록과 설정은 브라우저에서 삭제할 때까지 남을 수 있습니다. 통계 제공자가 처리하는 데이터의 보관·이전·권리 행사에 관한 내용은 해당 제공자의 안내를 확인해 주세요.

3. 쿠팡 파트너스 광고

메인 도감과 파자마 편집 영역 아래에 쿠팡 파트너스의 완구·취미 카테고리 베스트 상품을 보여주는 다이나믹 배너와 치이카와 상품 검색 링크를 표시합니다. 광고 영역에 제휴 수수료 안내를 표시하며, 해당 링크를 통한 구매에 따라 운영자에게 일정액의 수수료가 지급됩니다.

배너는 화면 가까이에 왔을 때 불러옵니다. 통계 수집이 켜져 있으면 광고 영역의 절반 이상이 1초 이상 보인 횟수와 치이카와 검색 링크 클릭을 기능 이벤트로 집계합니다. 이 노출 지표는 사이트 자체 기준이며, 배너 안의 상품 클릭·구매·수수료는 쿠팡의 리포트에서 별도로 집계됩니다.

다이나믹 배너를 불러올 때 쿠팡 광고 서버에 접속하며 IP 주소, 브라우저 정보 및 접속 주소가 전달될 수 있습니다. 광고 링크를 누르면 쿠팡으로 이동하고, 쿠팡은 자체 개인정보처리방침과 쿠키 정책에 따라 방문·구매 실적 등을 처리합니다. 도감의 메모·드로잉·사진 파일은 광고에 전달하지 않습니다.

사이트의 ‘Google 통계 설정’은 GA4 방문 통계에 적용되며 쿠팡 광고의 설정을 변경하지 않습니다. 쿠팡의 쿠키는 브라우저 설정 및 쿠팡의 안내에 따라 관리할 수 있습니다. 배너는 쿠팡이 발급한 외부 iframe 안에서 상품과 광고 스크립트를 불러옵니다. 도감의 메모·드로잉·사진 파일이나 편집 내용을 이 iframe에 전달하지 않습니다.

4. 영상과 외부 서비스

노래 TV를 열거나 영상 기능을 이용하면 YouTube 등 해당 서비스로 연결되어 IP 주소·기기 정보·재생 관련 정보가 전달될 수 있습니다. 외부 사이트의 링크를 누르면 해당 서비스의 개인정보 안내와 이용 조건이 적용됩니다.

웹사이트를 제공하는 GitHub Pages도 웹 요청을 처리하며 접속 관련 정보를 처리할 수 있습니다.
